# Assets

## reference
`reference/daibutsuame_reference.jpeg`

ユーザー提供の大仏飴キャラクター基準画像。
この画像をキャラクター継続性の正本として使用する。
外見変更が必要な場合はOwner承認を得る。

`reference/layout_stage_reference.webp`

Owner指定の紙芝居舞台（B）の画面構図の正本。座標は `config/layout.yaml`。
画像内の日本語文字は構図確認用の見本で、本番は動画編集段階で描画する。

## bgloop
`bgloop/night_river.webp`

Owner提供の背景画（夜の川辺の村）をそのまま複製したもの。背景ループ（`docs/BGLOOP.md`）の1シーン目。
`bgloop/<name>.yaml` は切り抜きのヒントと動きの設定。
