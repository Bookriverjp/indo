# チャンネル方針（2026-09-26 Owner決定）

## チャンネル
- 名前: 大仏飴のインド異聞
- 説明（YouTube のチャンネル説明に使う。正本は `config/channel.yaml`）:

> チンチラの語り部「大仏飴」が、インド各地に残る民話、怪異、伝説、昔話を訪ねます。
> ベンガル、ケーララ、カルナータカ、ラージャスターン、タミル、トゥル……。
> 有名な神話ではなく、村、森、寺院、家の戸口に残ってきた「もうひとつのインド」。
> 現地語資料・採話資料・研究資料を確認しながら、日本語で紹介します。

## いちばん大事なこと
「インドの怖い話チャンネル」にしない。
**怖い → 不思議 → 美しい → 笑える → 神秘的** まで扱う「インド民俗エンターテインメント」にして、大仏飴というキャラクターを長く育てる。

## 題材選びの考え方
- 初期は大仏飴がまだ知られていないので、題材の強さでクリックしてもらう。最初の10本は怖い話を多めにする
- 『パンチャタントラ』は邦訳・紹介・日本民話との比較研究がすでにあるので「初紹介」にはせず、比較企画に回す
- 地方語圏の怪異は日本語でまとまった紹介が少ないものが多い。ただし「日本初」とは言わない（確認できた範囲を research の japanese_coverage_notes に書く）
- 説明文の「現地語資料・採話資料・研究資料を確認しながら」を守る。Research Gate で信頼度 B 以上の出典を目標にする
