# スタイルガイド

## ブランド
「かわいい語り部 × 格調あるインド細密画 × 日本語で知られていない物語」

## 大仏飴
基準画像を最優先。
- 灰白色のチンチラ
- 赤い首輪
- 鈴
- 草を持つ
- かわいいが幼児向けに寄せすぎない
- 語り部として落ち着いた雰囲気

### 差分候補
- neutral
- talking
- surprised
- concerned
- thoughtful
- pointing
- scroll
- ending

## 本編絵柄
特定の現存作家を模倣するのではなく、歴史的なインド細密画の一般的特徴を参照する。
- Mughal / Rajput / Pahari / regional miniature traditions
- 細い輪郭
- 平面的な遠近
- 装飾的な植物・花・建築
- 金、深緑、藍、紅、象牙、朱
- 手漉き紙・絹のような質感
- 16:9を前提に、中央へ詰めすぎない

## 地域トーン
- Mughal: 宮廷、王侯、室内
- Rajput: 英雄、伝説、強い色
- Pahari/Kangra: 山、水、雨、恋、抒情
- Bengal: 川、湿潤、樹木、村、夜
- Kerala: 濃い緑、熱帯、雨、森

## 動き
推奨：
- slow push-in
- slow pan
- subtle parallax
- fog drift
- flame flicker
- rain layer
- cloud drift
- character entrance/exit
- slight scale/position change

避ける：
- 激しいカメラ
- 過度な3D化
- 連続的な大変形
- 毎カット別絵柄
- AI生成文字を画像に直接描かせる

## 字幕
文字は動画編集段階で重ねる。画像生成に日本語文字を描かせない。
