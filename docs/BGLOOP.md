# 背景ループ（1枚絵から動く背景）

1枚の背景画から、雲が流れ・川が流れ・木と草が風に揺れ・蛍と花びらが舞う、継ぎ目のないループ動画を作る。
AI動画は使わない。絵を層に分け、層ごとにプログラムで動かす（STYLE_GUIDE の「動き」の範囲）。

## Owner依頼（2026-09-27）
- 手作業で切り抜いた4枚のパーツを重ねるやり方では、雲・水辺・草木の境目が粗く、動きも物足りない。
- 1枚の絵から、雲の流れ・川の流れ・木の葉の揺れ・前ボケの花や葉・奥行きのある背景ループを、スクリプトで作る。
- 1シーン目：夜の川辺の村（`assets/bgloop/night_river.webp`、Owner 提供の絵をそのまま複製）。

## 使い方
```bat
python -m pipeline.bgloop assets/bgloop/night_river.yaml              # 切り抜き → 書き出し（約3分）
python -m pipeline.bgloop assets/bgloop/night_river.yaml --preview    # 確認用（960x540）
python -m pipeline.bgloop assets/bgloop/night_river.yaml --stage cut  # 切り抜きだけ（約15秒）
python -m pipeline.bgloop assets/bgloop/night_river.yaml --stage render --stills 0,360   # 1コマだけ PNG で
python -m pipeline.bgloop assets/bgloop/新しい絵.png --stage grid   # 座標の目盛りの絵と、シーン設定のひな形
```
出力は `output/bgloop/<name>/`（Git には入れない）。
- `loop.mp4`：1920x1080・30fps・24秒。最後のコマの次が最初のコマになる（プレイヤーのループ再生でつながる）
- `index.html`：確認用のページ（動画のループ再生と、切り抜いた層）
- `cut/`：層とマスク。`overlay.png` が切り抜きの確認用（空=藍・雲=白・水=水色・蓮=緑・舟と桟橋=橙・手前の草=黄・灯り=赤）

書き出しの長さ・大きさ・画質は `config/bgloop.yaml`。

## しくみ
### 切り抜き（`pipeline/bgloop/cut.py`）
シーンの YAML の「だいたいの範囲」と色の判定で大まかなマスクを作り、ガイド付きフィルタで元の絵の輪郭に沿わせる。
ヤシの葉の間の空や、草の穂の間の水も1画素単位で抜ける。層の色は背景の色を差し引いて求めるので、動かしても縁に元の背景の色が残らない。

| 層 | 中身 | 隠れていた所の補い方 |
|---|---|---|
| 空 `sky_plate.png` | 夜空・月・星 | 雲と陸の後ろを、見えている空の筆の模様を写して補う（同じ高さの近くから） |
| 雲 `clouds.png` | 金の縁取りの雲 | ヤシや木立に隠れていた雲の続きを補う（流しても葉の形の穴が出ない） |
| 陸 `land.png` | 空以外のすべて（木・家・岸・水・蓮・舟） | 手前の草の後ろの水と岸を、同じ高さの近くから写して補う |
| 手前の草 `foreground.png` | 左右の葦・バナナの葉・花 | — |

ほかに、水・映り込み・舟・蓮（ひとつずつ番号）・灯り（ひとつずつ番号）・星・奥行きのマスクを保存する。
マスクを画像編集で直したら `--stage render` で書き出しだけやり直せる。

### 動き（`pipeline/bgloop/render.py`）
| 動き | やり方 |
|---|---|
| 雲 | 風に乗って ゆっくり左右に漂い、形が大きくゆるやかにうねる（消えて入れ替わる瞬間を作らない） |
| 川 | 流れ（左へ・手前ほど速い）と波のゆらぎ。映り込みは流さず、細かく揺らして明るさをきらめかせる |
| 蓮・舟 | ひとつずつ位相をずらして上下に揺れる |
| 木・ヤシ | 風の波（左から右へ渡る）で揺れる。先ほど大きく、根元は動かない。葉は場所ごとに細かくざわめく |
| 手前の草 | 同じ風で、穂先ほど大きく揺れる。穂はさらに細かくそよぐ |
| 家・柵・灯籠 | 揺らさない（`protect`） |
| 灯り | 窓ごとに ゆらぎ、まわりに光がにじむ |
| 星・月 | 星はひとつずつまたたき、明るい星は光の十字が出る。月の光の輪がゆっくり呼吸する |
| 霧 | 夜空の薄い霧のすじと川霧がゆっくり流れる |
| 蛍・花びら | 蛍は岸と水面の上で明滅しながら漂う。花の木から花びらが散る |
| 前ボケ | 右上に、レンズのすぐ前の花の枝（ぼかした花の木の枝先）。大きくぼけた花びらが舞い落ちる |
| カメラ | ゆっくり楕円を描き、奥行きごとにずれ方を変える（パララックス） |

継ぎ目なくつながる理由：すべての動きの周期をループの長さの整数分の1にしている（`render_t(0)` と `render_t(24秒)` は同じ絵）。
流れのように一方向に進み続ける動きは、半周期ずらした2つを重みを変えながら重ね、巻き戻る瞬間の重みを0にする。

## 新しいシーンを作る
`assets/bgloop/<name>.yaml` を作る（`night_river.yaml` を写して直す）。座標は `ref_size` の絵での px。
1. `sky`：空がありうる範囲（`zone`）、月のだいたいの位置。空と色が近い木立があれば `grabcut` の範囲
2. `water`：水面の範囲、蓮の花の位置、舟・桟橋の矩形
3. `foreground`：手前の草の範囲（揺らす層）
4. `lights`：窓・灯籠の位置（円）
5. `depth`：奥行き（0=空の遠さ、1=手前の草）
6. `motion.sway`：揺らす木（ヤシは根元と先、ほかは範囲と根元）。`protect` に家など揺らさない物
7. `fx`：蛍・花びら・霧・前ボケ

`--stage cut` → `overlay.png` で切り抜きを確かめ、`--preview` で動きを確かめてから本番を書き出す。

## 制限
- 色で空・水・草を見分けるので、同じ色の物が重なる所（空と同じ藍の木立など）はシーンの YAML のヒントが要る。
- 大きく動かすと補った所が見える。揺れは数 px、雲の漂いは片側 約9px にとどめている。
- 雲は一方向へ流れ続けず、24秒で行って戻る（流れ続けるには、どこかで消して入れ替える必要があり、金の縁取りの雲では目立つため）。
- 描いた絵そのものは最後から最初へぴったりつながる。MP4 はつなぎ目（先頭）が唯一のキーフレームなので、そこで圧縮の細かい粒子が
  一度だけ入れ替わる（ふつうの動画のキーフレームと同じ程度。途中にはキーフレームを置かない）。紙芝居の書き出しに組み込むときは
  MP4 を経ずに `LoopRenderer` から直接コマを取れば、つなぎ目は出ない。
