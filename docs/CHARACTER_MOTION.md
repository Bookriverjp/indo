# 大仏飴の動きと表情

機械可読の正本は `config/character_motion.yaml`。外見の正本は `assets/reference/daibutsuame_reference.jpeg`。

## Owner決定（2026-09-26）
- 大仏飴は正面を向いて語る。
- 表情・動作はすべて動きを伴う。静止画のまま使わない。
- 作り方はパーツ分け方式（切り絵アニメ）。表情ごとにAI動画を生成しない。
- 下の一覧はすべて採用。

## 作り方
1. 基準画像から、パーツ（下表）を一度だけ作る。外見は変えない。
2. 瞬き・口パク・呼吸・揺れはレンダラーがプログラムで付ける。
3. 表情は目・口・耳・腕の状態の組み合わせで作る。
4. 涙・Zzz・「！」などは FX パーツとして重ねる。
5. パーツは全エピソードで使い回す。エピソードごとに大仏飴を生成しない。

## パーツ
| パーツ | 状態・動き | 支点 |
|---|---|---|
| body（頭と胴） | 呼吸、弾む、震え、揺れ | 足元 |
| ear_l / ear_r | 立つ、伏せる、ぴくっ | 耳の付け根 |
| eye_l / eye_r | open, half, closed, smile, wide, teary, sleepy | — |
| mouth | closed, small, open, wide, smile, frown, o, munch | — |
| nose | ひくひく | — |
| whisker_l / whisker_r | ひくひく、下がる | ひげの付け根 |
| arm_grass（草を持つ腕） | hold, point, chin, cover_mouth, hug, raise | 肩 |
| arm_free（もう一方の腕） | rest, raise, namaste | 肩 |
| bell（首輪の鈴） | 揺れ、鳴る | 首輪 |
| tail | ゆらゆら | 付け根 |
| fx | tear, sweat, zzz, exclaim, question, sparkle, gloom, dust, ring, whisper_dots | — |
| prop_scroll | 巻物（開く・閉じる） | — |

## 常時の動き（すべての表情に重なる）
| ID | 動き | 仕様 |
|---|---|---|
| `blink` | 瞬き | 2〜6秒の不規則な間隔、1回120ms。15%の確率で2回続ける。閉じ目の表情では止める |
| `lipsync` | 口パク | ナレーション音声の音量で closed / small / open を切り替える |
| `idle` | 待機 | 呼吸（体が1.5%ふくらむ、約3秒周期）、耳ぴくっ、鼻とひげのひくひく |

## 表情・動作
| ID | 名前 | 主な使い所 | 動き | 回数 |
|---|---|---|---|---|
| `point` | 草で指す | 説明、物語 | arm_grass=point、草の先が小さく揺れる | 何度でも |
| `scared` | 怖がる | 怪異の場面 | 耳を伏せる、体が小さく震える、草を胸に抱く、汗 | 何度でも |
| `laugh` | 笑う | 軽い話題、締め | 目=smile、口=wide、体が弾む | 何度でも |
| `cry` | 泣く | 悲しい結末 | 目=teary、涙が落ちる、ひげが下がる | 何度でも |
| `joy` | 喜ぶ | めでたい結末 | 両腕を上げる、耳が立つ、鈴が揺れる、キラキラ | 何度でも |
| `serious` | 深刻 | 重い史実・注意書き | 目=half、耳を後ろへ、動きを遅く、画面を少し暗く | 何度でも |
| `sleep` | 居眠り | 小ネタ | 目=sleepy→closed、舟をこぐ、Zzz → 鈴の音でびくっと起きる | 1本に1回まで |
| `surprise` | 驚く | 怪異が起きた瞬間 | 一瞬縮んで跳ねる、耳が立つ、「！」、鈴が鳴る | 何度でも |
| `think` | 考える | 異説・不確かな点 | 首をかしげる、arm_grass=chin、「？」 | 何度でも |
| `greet_namaste` | ナマステ | 冒頭のあいさつ | 両手を胸の前で合わせ、軽く頭を下げる | 冒頭 |
| `bow` | お辞儀 | 締め | 頭を下げて戻す | 締め |
| `bell_cue` | 鈴の合図 | 紙芝居の絵の差し替え | 首を振って鈴を鳴らす → 絵が抜けて次へ | 場面転換ごと |
| `nod` | うなずく | 相づち・納得 | 頭が小さく上下 | 何度でも |
| `head_shake` | 首を横に振る | 否定（「実際に起きたとは言えません」） | 頭が左右に揺れる | 何度でも |
| `whisper` | ひそひそ話 | 怪談の核心 | arm_grass=cover_mouth、体を少し縮める、小声の点々 | 何度でも |
| `munch` | 草をもぐもぐ | 怖い話のあとの間 | 口=munch、草を口元へ運ぶ | 何度でも |
| `scroll` | 巻物を広げる | 出典紹介 | prop_scroll が横に開く | 締め |
| `dust_bath` | 砂浴び | エンディング、お休み回 | 体を左右に転がす、砂けむり | 1本に1回まで |
| `popcorn` | ポップコーンジャンプ | 大喜び | 跳ねて空中でひねる | 1本に1回まで |
| `grooming` | 毛づくろい | 話の合間 | 手で顔をこする、小刻みに揺れる | 1本に2回まで |

## 注意
- 1本に1回までの動き（`sleep`、`dust_bath`、`popcorn`）は多用しない。語りのテンポが崩れる。
- 泣く・怖がるは伝承の登場人物を笑いものにする使い方をしない。
- 表情の選択は台本（script）の各段落に `expression` として付け、storyboard から timeline へ引き継ぐ。
