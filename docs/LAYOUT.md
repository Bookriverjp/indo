# 画面レイアウト

座標の正本は `config/layout.yaml`。モックアップ：https://claude.ai/artifact/EyyKigHLjm4S4i7XRbWnnr

## Owner決定（2026-09-26）
- 語り部の名前は「大仏飴」。
- 大仏飴は画面の右に固定。舞台・カードの方（左）を向くポーズで生成する。
- 地域・言語ラベルは常に表示する。
- 物語パートは B 紙芝居舞台。

## 3つのレイアウト
| ID | 名前 | 使う場面 | 大仏飴 |
|---|---|---|---|
| `stage` | B 紙芝居舞台 | 物語（基本） | 右に全身 |
| `fullbleed` | A 全面＋ワイプ | フック、物語の山場 | 右下の丸窓（フックでは出さない） |
| `card` | C 解説カード | 導入、地域・言語、解説・異説、比較、出典 | 右に全身・大 |

## 素材への影響
- 壁（`wall`）と紙芝居の枠（`frame`）は固定素材。エピソードごとに生成しない。
- 物語の絵は 16:9（1920×1080）で生成し、`stage` では 1280×720 に縮小、`fullbleed` ではそのまま、ショートでは正方形に切り出して使う。
- 大仏飴は透過背景の全身ポーズと丸窓用の顔アップを用意する。外見は `assets/reference/daibutsuame_reference.jpeg` から変えない。
- 字幕・地域ラベル・情報カードの文字は動画編集段階で描画する。画像生成に文字を描かせない。

## YouTube表示域
- 右下のチャンネル透かしロゴは使わない（大仏飴と重なるため）。
- 終了画面の要素（最後の20秒）は大仏飴を避けて配置する。
- 再生バー（下端90px）に字幕を掛けない。
- ショートは右側のボタン列と下部のタイトル表示を避け、丸窓を右上に置く。
