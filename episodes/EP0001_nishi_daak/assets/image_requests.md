# 画像の生成依頼（EP0001_nishi_daak）

1. 下の指示文で画像を作る（ChatGPT などの画像生成）。
2. できた画像を `episodes/EP0001_nishi_daak/assets/inbox/` に、指定のファイル名で保存する（png / webp / jpg）。
3. `python -m pipeline.images check EP0001_nishi_daak` を実行する。サイズ・透過をチェックして取り込む。

- 「透過: 必要」の素材は、背景を透明にした PNG で作る（依頼するときに「背景を透明にしたPNGで」と伝える）。
- 画像の中に文字・ロゴ・透かしを入れない。
- 同じ人物は、この回のすべての場面でこの1枚を使う。
